# Exhaust Manifold CFD Analysis & CAD Modeling

## 📌 Project Overview
This project focuses on the 3D geometry modeling and Computational Fluid Dynamics (CFD) simulation of a 4-runner exhaust manifold. The goal is to evaluate exhaust gas flow behavior and identify pressure drops and flow separation zones near the collector.

---

## 🛠️ Tools & Technologies Used
* **CAD Modeling:** CATIA V5
* **CFD Simulation:** Ansys Workbench / Fluent
* **Post-Processing:** Velocity and Pressure Contour Analysis

---

## 📁 Repository Structure
* `EXHAUST.CATProduct` — CATIA V5 Assembly / Surface Model
* `exhaust.wbpj` — Ansys Workbench Simulation Project File

---

## 🎯 Key Findings
* Analyzed exhaust gas flow velocity distribution across the manifold runners.
* Evaluated backpressure accumulation at the collector junction to guide geometry optimization.
